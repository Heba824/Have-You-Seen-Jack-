# 🎃 Have You Seen Jack? — Third-Person Narrative Prototype

A third-person Unity (URP) narrative prototype featuring custom character movement, animation blending, ground snapping physics, and continuous camera tracking.

[Watch the Gameplay Demonstration Video](https://drive.google.com/file/d/1nm4_Rl5cO3eACbSQhE1kluKq_FHFl3nO/view?usp=sharing)

## 🎮 Key Features & Mechanics
- **Custom Third-Person Controller:** Smooth movement vector calculations aligned with camera orientation.
- **Physics & Ground Snapping:** Custom ground-check logic and persistent velocity snapping to prevent character clip-through on floor colliders.
- **Animation Rigging:** Root Motion integration and looped locomotion clips with stabilized root transforms.
- **Universal Render Pipeline (URP):** Styled lighting and visual presentation.

## 🕹️ Controls
| Input | Action |
| :--- | :--- |
| **WASD / Arrow Keys** | Move Character |
| **Shift (Hold)** | Run / Sprint |
| **Spacebar** | Jump |
| **E** | Interact (Bed, Pick Up Items) |
| **Q** | Drink Potion |
| **F** | Drop Lantern |
| **V** | Change POV (First and Third) |
| **Right Mouse Button + Drag** | Orbit Camera |

## 🚀 How to Run the Project
1. Clone or download this repository as a `.zip`.
2. Open **Unity Hub** and click **Add** $\rightarrow$ select the project root folder.
3. Ensure you are using **Unity 6 (6000.0.3f1)** or any compatible URP version.
4. Navigate to `Assets/Scenes/` and open **`Assignment.unity`**.
5. Press the **Play** button in the Unity Editor to test.
